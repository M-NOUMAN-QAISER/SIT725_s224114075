## How the Application Works

**Frontend (Original Task 1.3P):**
1. Webpage displays **"SIT 725"** heading
2. **"Change Text"** button randomly updates heading via JavaScript DOM

**Backend (NEW Task 2.2P):**
1. Express server serves static files (`index.html` loads automatically)
2. **GET /add?a=10&b=5** → `{"result":15}`
3. **POST /calculate** → Supports add/subtract/multiply/divide

***

## Running the Project

### Frontend Only (Task 1.3P)
```
1. cd SIT725_224114075/1.3P
2. Open index.html in browser or VS Code Live Server
```

### Full Server (Task 2.2P - Recommended)
```
1. Clone repository
   git clone <repository-link>

2. Navigate to project
   cd SIT725_224114075/1.3P

3. Install dependencies
   npm install

4. Start server
   npm start    # OR: node server.js

5. Access:
   - Webpage: http://localhost:3000
   - API Test: http://localhost:3000/add?a=15&b=25
```

**API Testing Examples:**
```
GET:  http://localhost:3000/add?a=10&b=20
→ {"operation":"add","a":10,"b":20,"result":30}

POST: http://localhost:3000/calculate
Body: {"operation":"multiply","a":4,"b":6}
→ {"operation":"multiply","a":4,"b":6,"result":24}
```

## Key Endpoints

| Method | Endpoint | Description | Example |
|--------|----------|-------------|---------|
| GET | `/` | Health check & static files | Serves index.html |
| GET | `/add?a=5&b=3` | Add two numbers | `{"result":8}` |
| POST | `/calculate` | Calculator (add/subtract/multiply/divide) | `{"operation":"subtract","a":10,"b":4,"result":6}` |
